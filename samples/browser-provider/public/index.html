Browser provider

This page hosts an MCP server and publishes it to a broker slot over a WebSocket. The broker also serves this page, so there is one process and one origin.

Disconnected

1. Publish

Opt-in. With it on, this page's tools also appear on /_all/mcp, which is the slot an MCP host should be pointed at: _all exists before any provider connects and pushes tools/list_changed when this page joins.

2. Call it back, from this page

This runs a real MCP client against /<slot>/mcp. Because the request carries an Origin header, it is refused with 403 invalid_origin unless the broker was started with this page's origin in MCP_BROKER_ALLOWED_ORIGINS. Being served by the broker grants nothing.
